- (decision) Fast path. Redesign the existing responsive web app in a calm financial visual language: graphite surfaces, one soft accent, clear typography, restrained decoration. Dark mode is the only/default theme. Main workflows and API behavior remain intact; layout, hierarchy, navigation, states, and responsive UX may change.
- (decision) Primary surface is Plan: users need to understand monthly money available, adjust goal deadlines, inspect allocations, resolve conflicts, and push reviewed changes to YNAB. Settings is the secondary surface for connection and income configuration. Operational feedback uses sonner toasts.
- (event) spines finalized; separate UX reviewer gate declined; Plan is the key implementation surface, Settings and Login are spine-only
- (change) Replaced the green graphite/mint theme with Radix Colors dark Slate neutrals and Iris accents. Green now communicates success only; layout and interaction behavior remain unchanged.
- (change) Refined the timeline after visual feedback: compact goal list with progress and large touch actions below desktop, full drag timeline on desktop, and quieter deadline recommendations.
